# Resume‑to‑Portfolio Converter 🌐

A lightweight, browser‑based tool that converts résumé content into a simple, clean portfolio layout. This project includes multiple HTML versions representing different UI experiments, layout tests, and feature iterations.

## 🚀 Features
- 100% browser‑based — no installation required  
- Converts résumé text into a structured portfolio format  
- Multiple prototype versions included  
- MIT‑licensed and easy to extend  
- Great for students, job seekers, and personal branding projects  

## 📁 File Overview
This repository contains several HTML versions created during iterative development:

resume to portfolio converter 0.html
resume to portfolio converter 1.html
resume to portfolio converter 2.html
...
resume to portfolio converter 13.html

Each version explores different layouts, formatting logic, or UI interactions.

## ▶️ How to Use
1. Download or clone the repository  
2. Open any `.html` file in your browser  
3. Paste or upload your résumé content  
4. Export or copy the generated portfolio layout  

## 🛠 Customization
Because the project uses plain HTML/CSS/JS, you can easily:
- Adjust layout structure  
- Change color themes  
- Add animations or transitions  
- Integrate templates or custom sections  
- Build a full portfolio generator workflow
